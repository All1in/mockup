# Задача 1: Логін і логаут (45 хв)

**Стек:** React + TypeScript, Vite, react-router-dom. Для HTTP — нативний `fetch`, ніяких axios.

## Мета

Зробити щоб юзер міг залогінитись, бачити свої дані і вийти.

## Крок за кроком

### 1. `api.ts` — обгортка над fetch

- Завжди додає `credentials: 'include'` (щоб cookies літали)
- Завжди додає `Content-Type: application/json`
- Базовий URL бере з `VITE_API_URL`

### 2. `AuthContext`

- Стейт: `user` (об'єкт або `null`)
- При першому рендері — `GET /auth/me` (щоб після F5 юзер не зникав)
- Функції: `login(email, password)`, `register(email, password, name)`, `logout()`

### 3. Сторінки

- `/login` — два інпути + кнопка → `POST /auth/login`
- `/register` — три інпути + кнопка → `POST /auth/register`
- `/` — якщо є юзер: показати email, name, кнопка "Вийти"; якщо нема: посилання на логін

### 4. Помилки

- Помилки від сервера (невірний пароль, email зайнятий) — показати текст під формою

## Важливо

- Токени НЕ зберігаються на фронті — тільки HttpOnly cookies
- Всі запити з `credentials: 'include'` — інакше cookies не відправляться
- Відповідь від login/register містить `{ user, expiresIn }` — поки що використовуй тільки `user`

## Перевіряємо

- [ ] Зареєструвався → бачу свій email і name
- [ ] Залогінився → бачу свої дані
- [ ] Натиснув F5 → все ще залогінений
- [ ] Натиснув "Вийти" → дані зникли
- [ ] Ввів невірний пароль → бачу помилку
